# Start Java

Plataforma interativa para ajudar estudantes a aprender programação orientada a objetos com Java através de aulas teóricas, quizzes de fixação e um playground de execução de código em tempo real.

## Stack Técnica

- **Frontend:** React + TypeScript + Vite
- **Estilização:** Tailwind CSS
- **Navegação:** `react-router-dom`
- **Renderização de Conteúdo:** `react-markdown` + `remark-gfm`
- **Execução de Código Java:** API Serverless / Judge0 Community Edition (`ce.judge0.com`)
